## Upload GitHub

Khuyên tạo repository:

`kntoys-profile`

Sau đó upload toàn bộ file trong thư mục này vào root repository.

Cấu trúc:

kntoys-profile/
├── index.html
├── style.css
├── logo.svg
├── favicon.svg
├── og-cover.jpg
└── README.md

## Cloudflare Pages

- Production branch: `main`
- Framework preset: `None`
- Build command: để trống
- Root directory: `/`
- Build output directory: `/`

Sau khi Pages deploy thành công, vào:
Pages project → Custom domains → Add custom domain → `kntoys.vn`

Nếu `www.kntoys.vn` cũng được sử dụng, khuyên redirect:
`www.kntoys.vn` → `https://kntoys.vn`

## Lưu ý

`logo.svg` hiện là logo chữ KN TOYS được dựng tạm để website hoàn chỉnh ngay.
Nếu bạn có logo KN TOYS chính thức, có thể thay file `logo.svg` hoặc đổi thành `logo.png`
và sửa đường dẫn ảnh trong `index.html`.
